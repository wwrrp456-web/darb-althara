# المرحلة د — تطبيق الهوية وتجربة القرار

نقطة البداية: `63a15f977d52f63539d491c16e9bbea8c1edba82`. استُخدم الاتجاه الكرتوني ١ والتخطيط المعتمدان. هذه دفعة التطبيق البصري؛ إعداد النمطين والنهايات وقياسات العائلات من المرحلة هـ.

## ما طُبّق

- الشعار في البداية وشريط اللعبة واللوحة والتذييل ودليل الهوية وأيقونات التثبيت والمشاركة، مع اسم عربي مضبوط خارج الرسم المولد.
- أزرق للتنظيم، وعاجي للمساحات، وساج محدود وذهب للأهداف ومرجاني للتنبيه، مع الاحتفاظ بالرسوم الكرتونية والشخصيات المتنوعة الحالية. لم تُنتج أطالس جديدة أو شخصيات إضافية.
- بطاقات موحدة بعناوين وأرقام حقيقية؛ إرشاد مفتوح أول مرة لكل نوع خلال التبويب، يمكن طيّه واستعادته بلوحة المفاتيح. لا يقفل الإرشاد أي نظام أو يخفي الشروط المالية.
- مقارنة النقد والدخل والمصاريف والسعادة منذ آخر اختيار مالي في «بطاقتي» والقائمة المالية. المقارنة نسخ بدائية من العرض، وليست حقول حفظ جديدة. توضح أنها تشمل الأحداث اللاحقة ولا تعزل السببية لقرار واحد. تختفي بعد إعادة التحميل؛ لا تظهر صفوف بلا تغير، ولا تستبدل الموافقات الصريحة.
- أصوات الرمي والتحذير أقل حدة؛ بقي زر الكتم وتفضيله الحاليان. احترام تقليل الحركة يشمل اهتزاز التحذير وحركة النوافذ والزينة.
- إصدار الأصول `darb-journey-v16` وتهيئة التطبيق للدوران؛ لا تغيير لقواعد المباراة أو القيم المالية أو بروتوكول الشبكة أو إصدار الحفظ ومفتاحه.

## تسليم الشعار

ملفات `icons/logo-{horizontal,horizontal-dark,vertical}.{svg,png}` و`logo-wordmark.svg` و`logo-symbol.png`، والرمز المبسط والأيقونات الآمنة للتثبيت. الرموز الكرتونية PNG شفافة داخل SVG؛ **ليست رسماً متجهياً خالصاً**. الكتابة وحدها مسارات متجهية مشتقة من Tajawal المرخص. النسخة الأحادية `brand-mark-mono.svg` ظل موحد، لا تدّعي المحافظة على التفاصيل الملونة. [دليل الهوية](../../brand/index.html) يشرح المساحة الآمنة والحد الأدنى والألوان والاستخدامات والتنزيلات، ومعه PDF محدث.

الأصل الكامل صُدّر 512×512 إلى `logo-symbol.png` ثم ضُمّن في التركيبات لتقليل الحجم؛ رمز الأحجام الصغيرة هو النسخة المبسطة المعتمدة. يعيد `tools/export_journey_brand.py` إنتاج التركيبات والأيقونات والمشاركة والدليل عبر Chromium. المصادر المعتمدة محفوظة في المرحلة ب؛ صور التقرير والـPDF ليست ضمن تنزيل التطبيق الأول أو عامل الخدمة.

## التحقق

النتائج التفصيلية في ملفات JSON المجاورة. أوامر إعادة الفحص بعد تشغيل خادم المستودع على المنفذ 8000:

```sh
python3 tools/verify_journey.py
python3 tools/verify_identity.py
python3 tools/run_presentation_checks.py cards --artifacts /tmp/darb-d-cards
python3 tools/run_presentation_checks.py camera --artifacts /tmp/darb-d-camera
python3 tools/verify_upgrade.py --previous-ref 63a15f9
python3 tools/measure_tabletop.py --output /tmp/darb-d-performance.json
```

- خمس شاشات بداية وعشر حالات لعب: لاعبان وثمانية × المقاسات الخمسة المعتمدة؛ لا تمرير أفقي، ولا تحكم ظاهر أصغر من 48px، والمشهد لا يقل عن 180px والأوامر ضمن الارتفاع.
- شراء فعلي ورفض وتأمين وتعلم وعائلة وسؤال بترتيب إجابات متغير؛ صحة التكلفة والأثر وبقاء قواعد البيانات الرقمية.
- المقارنة والإرشاد لا يغيران JSON حالة اللعب، مع فحص شراء فعلي وعرض فرق النقد والدخل. حفظ واستعادة ورمية، وتحميل الأصول ودون اتصال، وتنزيلات دليل الهوية، ودعم لون النظام الفاتح والداكن دون أخطاء JavaScript أو HTTP في السيناريو المفحوص.
- فحوص الكاميرا: سحب وفأرة ولمس وتكبير ومفاتيح ومتابعة، واستعراض دون تعديل حالة المباراة وأولوية القرارات.
- ترقية v15 إلى v16 بمباراة محفوظة: الأسماء والمهن والنقد محفوظة، وإعادة الفتح بعد إيقاف الخادم ناجحة. لم يُضف حقل إلى الحفظ.
