# متابعة التباين — عينة قبل إصلاح اقتطاع الأطالس

مرجع القياس: `d952903233faee448b173e04e032ec747b7a19b5`. اكتمل هذا الفحص أثناء متابعة التباين، قبل أن يرسل صاحب المشروع مثال الشنطة المقصوصة؛ لا تستخدم صوره لإثبات إصلاح الأيقونات اللاحق.

- فُحصت15 تركيبة فعلية من ألوان أرقام اللاعبين الثمانية وعداد المجموعة وأسماء الرزم والنص الثانوي وأزرار مختارة. أقل نسبة4.613:1، وأقل نسبة للأرقام البيضاء فوق ألوان اللاعبين4.923:1. في الخلفية الفاتحة الشفافة استُخدم تركيب فوق الأسود كحد محافظ، لا افتراض أن الصورة تحتها بيضاء.
- أخذت عينات من خلفية حروف عنوان الدور على الجوال390×844 والتابلت1180×820، بالمنظورين ومن اسم قصير وطويل. أُخفي النص مؤقتاً في المتصفح لقراءة الخلفية نفسها، واستُبعد ظله من القياس. أقل نسبة مرصودة10.477:1.
- عدد الحروف ذات البكسلات شبه المعتمة قليل في ثلاث عينات جوال:3 و17 و27 بكسلاً؛ هذه قرائن محدودة، ولا تثبت وضوح الكتابة الصغيرة أو الحروف المضادة للتعرج. خمس عينات أخرى تتضمن145–845 بكسلاً.

[البيانات الكاملة](checks.json) وصور العرض محفوظة هنا. لم يظهر فشل تباين في العينة، لذلك لم تتغير ألوان اللعبة. هذه ليست شهادةWCAG أو إغلاقاً للملاحظات الـ31: لا تغطي العينة كل النصوص أو تراكب النوافذ أو جميع صور الخلفية، ولا تعوض أجهزة فعلية أو قارئ شاشة أو تدقيق الحجم والقراءة.

لإعادة القياس بعد تشغيل خادم المستودع علىlocalhost:8000:

```sh
python3 tools/verify_board_contrast.py --output /tmp/darb-contrast
```

البرنامج يحلل لقطات عرض المتصفح ولا يعدّل ملفات الرسوم. نتائج إصدار لاحق لا تستبدل البيانات التاريخية هنا تلقائياً. إصلاح اقتطاع الأيقونات موثق مستقلاً في [تقرير الرسومات](../sprite-fix/README.md).
