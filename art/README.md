# رسوم اللعبة

رسوم الشخصيات والبضائع ولوحة السوق في هذه اللعبة **مولّدة بالذكاء الاصطناعي عبر Canva** (أداة Generate Image)، بأسلوب موحّد ومن أوصاف كتبناها.

- `trader`, `teacher`, `nurse`, … : بورتريهات المهن (٢٠٠×٢٠٠).
- `g_dates`, `g_coffee`, `g_perfume`, `g_fabric`, `g_honey`, `g_saffron` : أيقونات البضائع.
- `hero` : لوحة السوق الشعبي لشاشة الترحيب.

النسخة المضمّنة داخل `index.html` مصغّرة بصيغة WebP (≈٩٢ كيلوبايت لكل الرسوم) لتبقى اللعبة ملفاً واحداً يعمل بلا إنترنت.

> راجع شروط استخدام Canva للمحتوى المولَّد قبل نشر اللعبة تجارياً.
