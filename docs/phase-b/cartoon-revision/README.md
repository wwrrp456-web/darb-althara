# استكشاف الشعار الكرتوني — الجولة الثانية

توجيه صاحب المشروع: اتجاهات الشعار السابقة غير مناسبة، والمطلوب أن يتبع الشعار أسلوب رسوم اللعبة الكرتونية. هذه الجولة تستكشف الرمز والكتابة معاً؛ لا تطبق شعاراً أو تعدل اللعبة.

[صورة المقارنة](comparison.png) · [صفحة المقارنة التفاعلية](index.html) · [نتائج فحص الصفحة](checks.json).

| الفكرة | المعنى | ما يحتاج تنقيحاً إذا اختيرت |
| --- | --- | --- |
| ١ — خطوة إلى الحلم | خانات لوحة وقطعة لاعب تصعد إلى نجمة | تقليل اللمعات وتبسيط الخانات في الرمز الصغير |
| ٢ — مفتاح الفرصة | مشروع حي صغير يفتح باب دخل | تقليل تفاصيل المبنى وتكبير المفتاح؛ التمييز عن أيقونة متجر عادية |
| ٣ — الفرصة تجمعنا | نرد ومتسابقون ومسار دائري | ضبط توازن النرد والقطع وربط المعنى بالرحلة المالية |
| ٤ — حكاية تبنيها | كتاب تتحول صفحاته إلى عالم فرص | تبسيط المشهد واختبار ألا يبدو علامة تعليم عامة فقط |

الرسوم مولدة باستخدام صورة الهوية المعتمدة وأطلس المباني الحالي مرجعين للأسلوب. ملف `concepts.png` شفاف، شبكة ٢×٢، يُعرض في CSS دون تعديل الصور الأصلية. الاسم «درب الثراء» كتابة عربية فعلية بخط Tajawal المحلي، مع لون وحد وتظليل لاستكشاف المعالجة الكرتونية؛ ليس كتابة عربية مولدة داخل الصورة أو خطاً مخصصاً نهائياً. لكل اتجاه معالجة لونية أولية للكتابة لا اسم لعبة جديد.

هذه ليست حزمة شعار نهائية: لا اعتماد أو ادعاء قراءة عند 32px أو صلاحية مباشرة لأيقونات التثبيت. بعد اختيار الفكرة يُبسّط الرمز ويُضبط الاسم والتركيب معاً، ثم تعرض البداية وشريط اللعب والأيقونة بأحجامها الفعلية قبل اعتمادها وتعميمها.

تحقق المتصفح من عدم التمرير الأفقي على 360×640 و390×844 و768×1024 و1180×820، ومن أزرار معاينة الأفكار الأربع، دون أخطاء JavaScript أو HTTP. لا يمثل هذا اختبار تعرف الجمهور على الشعار. صدّرت نسخة مستقلة محلية إلى `/workspace/darb-althara-cartoon-logos.html` تحتوي الصور والخطوط داخل الملف للمراجعة القابلة للتنزيل؛ ملفات المصدر هنا لا تعتمد على حزم أو خدمة خارجية.

الشعارات الثلاثة القديمة مرفوضة بحسب التوجيه الأخير. لم يُفترض اعتماد النموذج السابق لتخطيط اللعب أو رفضه؛ لم يعلق صاحب المشروع عليه في هذه الرسالة.

لإعادة إنتاج ملف المراجعة المستقل:

```sh
python3 docs/phase-b/cartoon-revision/make_review.py --output /tmp/darb-althara-cartoon-logos.html
```
