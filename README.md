# درب الثراء

لعبة لوحية تعليمية فردية بالعربية: اخرج من «سباق الفئران» ببناء دخل سلبي يغطي مصاريفك، ثم حقّق حلمك في «المسار السريع».

## التشغيل
افتح `index.html` في أي متصفح — لا حاجة لتثبيت أو خادم. يُحفظ التقدم تلقائياً في المتصفح.

## الدليل
[دليل المستخدم الكامل (PDF)](darb-althara-guide.pdf) — شرح اللعبة بالصور: الشاشة، المهن، الخانات، الصفقات، القروض، المسار السريع، الجداول والمصطلحات.

داخل اللعبة زر **؟** أعلى الشاشة يعرض شرح الأساسيات (الفكرة، الخانات، المصطلحات، نصائح)، ويظهر تلقائياً عند أول تشغيل.
