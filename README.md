# درب الثراء

لعبة لوحية تعليمية بالعربية: اخرج من «سباق الفئران» ببناء دخل سلبي يغطي مصاريفك، ثم حقّق حلمك في «المسار السريع».

## اللاعبون
- 👤 لاعب أو أكثر على نفس الجهاز بالتناوب
- 🤖 منافس آلي بمستويين (مبتدئ / ماهر)
- 🌐 صديق عن بُعد: اتصال مباشر بين الجهازين بتبادل رمزين (نسخ ولصق) دون خادم أو حساب

حتى ٤ لاعبين، وأول من يحقق حلماً يفوز.

## التشغيل
افتح `index.html` في أي متصفح — لا حاجة لتثبيت أو خادم. اللعب الفردي والآلي وعلى نفس الجهاز يُحفظ تلقائياً في المتصفح.

## الدليل
[دليل المستخدم الكامل (PDF)](darb-althara-guide.pdf) — ٢٠ صفحة بالصور: الراتب والشهور، الشاشة، المهن، الخانات، الصفقات والقروض، المسار السريع، المنافسون واللعب مع صديق، الجداول والمصطلحات.

داخل اللعبة زر **؟** يعرض الشرح (الفكرة، الراتب والشهور، الخانات، المنافسون، المصطلحات، نصائح)، ويظهر عند أول تشغيل.
