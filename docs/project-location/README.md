# الوصول إلى المشروع على اللوحة

2026-10-28 · متابعة إخراج الطاولة بعد `e55c75c` · إصدار الأصول `darb-locate-v21`.

أضيف زر **«أظهر على اللوحة»** أعلى معلومات المشروع ليظهر على الجوال قبل قائمة الأرقام. صُحح أيضاً وصف المشروع الذي كان يُسمى رزمة عند فتحه من القائمة. يمكن فتحه من قائمة المشاريع أو بالضغط على الخانة؛ يغلق المعلومات ويوسّط المشروع ويقربه بالقدر اللازم للقراءة ويحدد حدوده داخل الخانة. لا تتغير أموال أو ملكية أو مواضع اللاعبين أو حالة المباراة. يتوقف تتبع اللاعب عند هذا التدخل، ويمكن استعادته بزر المتابعة. زر اللوحة كاملة يمسح التحديد ويعيد النظرة العامة.

الزر لا يظهر للرزم والشخصيات والخانات غير الاستثمارية. يحتفظ المشهد بالتركيز بعد التنفيذ، ويحمل اسم المشروع في تسميته لقارئ الشاشة. لا حركة تلقائية مستمرة أو أصول صور جديدة، ولا تغيير للقواعد أو الحفظ v10 أو بروتوكول 2 أو إعدادات النشر.

## التحقق

- `python3 tools/verify_project_location.py`: [40 حالة لجميع المشاريع](checks.json)، المساران × خمسة مقاسات، استهداف الخانة الصحيحة وتوسيطها، التفعيل بالمفاتيح وإعادة التركيز، إعادة النظرة العامة، إخفاء الزر للرزم وأولوية القرار الإلزامي. مقارنة JSON المباراة قبل الاستعراض وبعده.
- [فحوص الكاميرا السابقة](camera.json): السحب واللمس والمفاتيح والتتبع وحدود التكبير والاستعراض دون أخطاء JavaScript.
- [فحص axe الآلي](accessibility.json): دون مخالفات مكتشفة في 13 شاشة مختبرة، مع [فحص إضافي لمعلومات المشروع والمشهد المحدد](action-accessibility.json)؛ لا يعادل اختبار قارئ شاشة فعلياً.
- [ترقية v20 إلى v21](upgrade.json): بقاء المباراة والعمل دون اتصال بمحاكاة فصل الشبكة.

لم تجر اختبارات هاتف فعلي أو Safari أو قارئ شاشة أو عائلات بهذه المتابعة؛ متطلبات التحقق الميداني للمرحلة هـ مستمرة. لا نشر موقع أو إعداد Pages. قياس أداء v20 في التقرير السابق تاريخي ولم يُعد بهذه الدفعة، إذ لا توجد حلقة تحريك جديدة.
